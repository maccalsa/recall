## Code navigation

| Action | Linux | macOS | Description |
|--------|-------|-------|-------------|
| Search everywhere | `Shift` `Shift` | `Shift` `Shift` | Files, classes, actions |
| Go to file | `Ctrl + Shift + N` | `Cmd + Shift + O` | Open file by name |
| Go to class | `Ctrl + N` | `Cmd + O` | Jump to class |
| Go to definition | `Ctrl + B` | `Cmd + B` | Jump to symbol |
| Go to implementation | `Ctrl + Alt + B` | `Cmd + Alt + B` | Implementation |
| Find usages | `Alt + F7` | `Alt + F7` | Usages of symbol |
| Recent files | `Ctrl + E` | `Cmd + E` | Recent files |
| Navigate back | `Ctrl + Alt + ←` | `Cmd + [` | Back |
| Navigate forward | `Ctrl + Alt + →` | `Cmd + ]` | Forward |

## Custom / advanced

| Action | Linux | macOS | Description |
|--------|-------|-------|-------------|
| Find action | `Ctrl + Shift + A` | `Cmd + Shift + A` | Any action by name |
| Live templates | `Ctrl + J` | `Cmd + J` | Insert live template |
| Generate | `Alt + Insert` | `Cmd + N` | Generate code |

## Notes

- Prefer **Search everywhere** (`Shift` `Shift`) for navigation.
- **Find action** (`Ctrl + Shift + A`) finds any command by name.
