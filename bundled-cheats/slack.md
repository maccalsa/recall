Keyboard reference for the **desktop app**. Linux uses **Ctrl** where macOS uses **Cmd**. The web client may differ; open the in-app shortcut list with **Ctrl + /** (Linux) or **Cmd + /** (macOS).

## Find what needs you

These three views cover most “where did that go?” cases:

| Goal | Linux | macOS | What it shows |
|------|-------|-------|---------------|
| Direct asks to you | `Ctrl + Shift + M` | `Cmd + Shift + M` | Mentions, thread replies to you, reactions — closest to an inbox |
| Threads you are in | `Ctrl + Shift + T` | `Cmd + Shift + T` | Threads you participate in |
| All unreads | `Ctrl + Shift + A` | `Cmd + Shift + A` | Scan unreads without living in every channel |

There is no separate “group-only” inbox: use **Mentions**, **Threads**, **All unreads**, and **Search**. If you were not @mentioned and not in the thread, Slack does not guarantee the message appears in your views.

## Navigation and views

| Action | Linux | macOS | Notes |
|--------|-------|-------|-------|
| Quick switcher | `Ctrl + K` | `Cmd + K` | Jump to any conversation |
| Search in conversation | `Ctrl + F` | `Cmd + F` | Find in current view |
| Back / forward | `Alt + ←` / `Alt + →` | `Cmd + [` / `Cmd + ]` | History |
| Shortcut list | `Ctrl + /` | `Cmd + /` | In-app shortcuts |

## Search operators

Use global search (quick switcher or search bar):

| Need | Example |
|------|---------|
| From one person | `from:@username` |
| Mentions of you | `mentions:me` |
| Combined | `from:@alice mentions:me` |

**Notification keywords** (Preferences → Notifications): add keywords (name, `?`, etc.) so matching messages surface in notifications.

## Compose and threads

| Action | Linux | macOS |
|--------|-------|-------|
| Edit last message | `↑` | `↑` |
| New line (do not send) | `Shift + Enter` | `Shift + Enter` |
| Reply in thread | `Ctrl + Shift + Enter` | `Cmd + Shift + Enter` |

Open thread from the thread indicator on the message.

## Saved, reminders, pins

| Action | How |
|--------|-----|
| Save for later | Message menu → Save (bookmark) |
| Open Saved | Sidebar → **Saved** (shortcut varies; check `Ctrl + /`) |
| Reminder | `/remind me in 1h` or message menu |
| Pin | Message **…** → Pin to channel |

## Sidebar and UI

| Action | Linux | macOS |
|--------|-------|-------|
| Toggle sidebar | `Ctrl + Shift + D` | `Cmd + Shift + D` |
| Star channel / DM | Right-click conversation → Star | Same |

## Lost message checklist

1. **Mentions** — `Ctrl + Shift + M`
2. **Threads** — `Ctrl + Shift + T`
3. **DMs** — check list for new thread activity
4. **Search** — `from:@person`, `mentions:me`, or keywords

## Mental map

| Slack UI | Use it for |
|----------|------------|
| Mentions | Someone wants **you** |
| Threads | Discussions you joined |
| Saved | Backlog / follow-up |
| All unreads | Background sweep |
| Channels | Everything else until pulled in (mention / thread / save) |
