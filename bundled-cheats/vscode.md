## General

| Action | Shortcut (Linux/Win) | macOS |
|--------|----------------------|-------|
| Command Palette | `Ctrl+Shift+P` | `Cmd+Shift+P` |
| Quick Open file | `Ctrl+P` | `Cmd+P` |
| Settings UI | `Ctrl+,` | `Cmd+,` |
| Keyboard Shortcuts | `Ctrl+K Ctrl+S` | `Cmd+K Cmd+S` |
| Toggle Sidebar | `Ctrl+B` | `Cmd+B` |
| Toggle Terminal | `` Ctrl+` `` | `` Cmd+` `` |

## Navigation

| Action | Linux/Win | macOS |
|--------|-----------|-------|
| Go to line | `Ctrl+G` | `Ctrl+G` |
| Go to symbol in file | `Ctrl+Shift+O` | `Cmd+Shift+O` |
| Go to definition | `F12` | `F12` |
| Peek definition | `Alt+F12` | `Option+F12` |
| Go back / forward | `Alt+←` / `Alt+→` | `Ctrl+-` / `Ctrl+Shift+-` |
| Breadcrumb focus | `Ctrl+Shift+.` | `Shift+Cmd+.` |

## Editing

| Action | Linux/Win | macOS |
|--------|-----------|-------|
| Move line up/down | `Alt+↑` / `Alt+↓` | `Option+↑` / `Option+↓` |
| Copy line up/down | `Shift+Alt+↑` | `Shift+Option+↑` |
| Delete line | `Ctrl+Shift+K` | `Shift+Cmd+K` |
| Comment line | `Ctrl+/` | `Cmd+/` |
| Format document | `Shift+Alt+F` | `Shift+Option+F` |
| Rename symbol | `F2` | `F2` |

## Search & Replace

| Action | Linux/Win | macOS |
|--------|-----------|-------|
| Find in file | `Ctrl+F` | `Cmd+F` |
| Replace in file | `Ctrl+H` | `Cmd+Option+F` |
| Find in files | `Ctrl+Shift+F` | `Cmd+Shift+F` |
| Next / previous find | `F3` / `Shift+F3` | same |

## Terminal

| Action | Linux/Win | macOS |
|--------|-----------|-------|
| New terminal | `` Ctrl+Shift+` `` | `` Ctrl+Shift+` `` |
| Split terminal | `Ctrl+Shift+5` | `Cmd+\` |
| Focus editor / terminal | `` Ctrl+` `` | `` Cmd+` `` |

## Multi-cursor

| Action | Linux/Win | macOS |
|--------|-----------|-------|
| Add cursor above/below | `Ctrl+Alt+↑` / `↓` | `Cmd+Option+↑` / `↓` |
| Add next occurrence | `Ctrl+D` | `Cmd+D` |
| Select all occurrences | `Ctrl+Shift+L` | `Cmd+Shift+L` |
| Column (box) selection | `Shift+Alt+drag` | `Shift+Option+drag` |

## Debug

| Step Into | `F11` | `F11` |
| Step Out | `Shift+F11` | `Shift+F11` |

@installed                     filter installed
@recommended                   workspace recommendations
